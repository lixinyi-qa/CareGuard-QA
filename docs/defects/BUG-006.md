# BUG-006 已确认告警可被重复确认

- 类型：状态机/幂等性 / 缺陷注入与回归演练
- 严重度：S2；优先级：P1；状态：Verified
- 影响版本：fault-injection baseline；修复版本：1.0.0

## 复现步骤

1. 家属第一次确认 open 告警。
2. 另一客户端或同一客户端再次确认相同 ID。
3. 查看 acknowledged_at 和审计记录。

预期：第一次 200；第二次 409 `ALREADY_ACKNOWLEDGED`，首次确认信息不被覆盖。
注入基线实际：两次均 200，后一次覆盖确认人和时间。

## 影响、根因与修复

重复写破坏“谁先关怀”的审计事实。修复在状态转换前验证只允许 `open → acknowledged`，其他状态返回冲突。

回归证据：`test_alert_can_be_acknowledged_once`。
