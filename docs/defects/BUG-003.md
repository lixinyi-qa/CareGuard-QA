# BUG-003 同一家庭关系可重复创建

- 类型：数据一致性 / 缺陷注入与回归演练
- 严重度：S2；优先级：P1；状态：Verified
- 影响版本：fault-injection baseline；修复版本：1.0.0
- 前置：同一老人和家属已有 pending/active/revoked 关系

## 复现步骤

1. 家属再次提交相同老人手机号。
2. 查询 `care_links` 的相同 `(elderly_id, family_id)` 组合。

预期：409 `LINK_EXISTS`，数据库仍为一条。
注入基线实际：重复插入，老人看到多条邀请，权限与告警查询可能重复。

## 影响、根因与修复

根因是仅依赖应用查询且表无唯一约束，并发时会绕过。修复增加 `uq_care_link_pair` 数据库唯一约束，同时在 API 提前返回可读的 409。SQL `DQ-006` 检测存量重复。

回归证据：`test_duplicate_link_is_rejected`、`test_phone_column_has_unique_constraint`（同类数据库约束策略）和 `sql/consistency_checks.sql`。
