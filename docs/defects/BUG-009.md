# BUG-009 连续消极每次打卡重复生成告警

- 类型：业务规则/告警风暴 / 缺陷注入与回归演练
- 严重度：S2；优先级：P1；状态：Verified
- 影响版本：fault-injection baseline；修复版本：1.0.0

## 复现步骤

1. 老人连续提交 3 条消极记录，生成 streak 告警。
2. 在七天内继续提交第 4、第 5 条消极记录。
3. 统计 open `negative_streak` 告警。

预期：未确认且七天内只保留一条同类告警。
注入基线实际：每新增一条都满足“最近三条消极”，产生告警风暴。

## 影响、根因与修复

重复告警造成家属疲劳并降低真正高关注消息的可见性。修复在创建前查询七天内同老人、同类型、open 告警；高关注告警仍单独生成，不被低级别去重吞掉。

回归证据：`test_three_negative_checkins_create_one_streak_alert` 和 TC-030。
