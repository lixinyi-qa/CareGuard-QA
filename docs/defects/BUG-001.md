# BUG-001 已绑定家属可读取老人情绪原文

- 类型：隐私越权 / 缺陷注入与回归演练
- 严重度：S1；优先级：P0；状态：Verified
- 影响版本：fault-injection baseline；修复版本：1.0.0
- 环境：FastAPI + 任意受支持数据库；老人和家属关系为 active

## 复现步骤

1. 老人提交只希望本人看到的情绪文字。
2. 已绑定家属携带自己的 Token 请求 `GET /api/v1/moods?owner_id={elderlyId}`。
3. 检查响应第一条的 `text`。

预期：家属只能获得分类、时间、置信提示和统计，`text=null`。
注入基线实际：序列化层直接复用老人响应对象，返回完整原文。

## 影响、根因与修复

情绪文字属于高敏个人数据，泄露会破坏知情同意边界。根因是“有记录读取权”等同于“有所有字段读取权”。修复在 DTO 转换时显式计算 `include_text = owner/admin`，家属路径强制置空，UI 同时显示隐私提示。

回归证据：`tests/test_api.py::test_linked_family_sees_label_but_not_raw_text`；Postman “Family reads labels but raw text is redacted”。
