# BUG-004 高关注告警文案复制原始敏感文本

- 类型：隐私/安全文案 / 缺陷注入与回归演练
- 严重度：S1；优先级：P0；状态：Verified
- 影响版本：fault-injection baseline；修复版本：1.0.0

## 复现步骤

1. 老人提交包含高关注表达的情绪文字。
2. 已绑定家属查询 `/alerts`。
3. 检查告警 `message` 是否包含原文或诊断结论。

预期：只返回固定的通用关怀指引，不复制原文，不声称诊断。
注入基线实际：告警使用字符串模板拼入情绪原文。

## 影响、根因与修复

告警本应共享最小必要信息，复制原文绕开了 BUG-001 的字段脱敏。修复改为固定、评审过的关怀消息，Alert 仅保存源记录 ID，不保存第二份原文；高关注标志不等于诊断。

回归证据：`test_high_risk_checkin_creates_generic_alert_without_leaking_text`；Postman “Family lists care alerts”。
