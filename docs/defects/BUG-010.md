# BUG-010 页面缺少关键浏览器安全响应头

- 类型：Web 安全加固 / 缺陷注入与回归演练
- 严重度：S2；优先级：P1；状态：Verified
- 影响版本：fault-injection baseline；修复版本：1.0.0

## 复现步骤

1. 请求 `/` 或 `/health`。
2. 查看响应头 CSP、X-Content-Type-Options、X-Frame-Options、Referrer-Policy。

预期：限制资源同源、禁止 MIME 嗅探和 iframe 嵌入，并回传请求关联 ID。
注入基线实际：以上安全头缺失，页面可被第三方 iframe 嵌入。

## 影响、根因与修复

缺少浏览器侧防御会扩大 XSS/点击劫持影响。修复通过统一中间件添加严格同源 CSP、`nosniff`、`DENY`、`same-origin` 和响应耗时/关联 ID。当前本地存储令牌仍记录为生产迁移风险，建议正式环境使用 Secure + HttpOnly + SameSite Cookie。

回归证据：`test_security_headers_are_present`。
