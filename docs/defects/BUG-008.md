# BUG-008 全空格情绪文本可写入

- 类型：输入校验/数据质量 / 缺陷注入与回归演练
- 严重度：S2；优先级：P1；状态：Verified
- 影响版本：fault-injection baseline；修复版本：1.0.0

## 复现步骤

1. 老人提交 `{"text":"   "}`。
2. 查询情绪历史和数据库。

预期：422，提示内容不能为空，不产生记录/统计。
注入基线实际：长度大于 0 因而通过，保存无意义 neutral 记录。

## 影响、根因与修复

空记录污染趋势并可能干扰连续情绪判断。根因是只用 `min_length=1`，没有规范化空白。修复在 Pydantic 字段验证器中 `strip()` 后再次判空，数据库检查 `DQ-013` 发现存量问题。

回归证据：`MoodCreate.not_blank`、TC-023、`DQ-013 blank raw mood text`。
