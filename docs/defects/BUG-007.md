# BUG-007 未绑定家属可为任意老人创建提醒

- 类型：对象级越权（BOLA）/ 缺陷注入与回归演练
- 严重度：S1；优先级：P0；状态：Verified
- 影响版本：fault-injection baseline；修复版本：1.0.0

## 复现步骤

1. 使用未绑定家属 Token。
2. 在新增提醒正文中把 `owner_id` 改为任意已知老人 ID。
3. 查询该老人提醒。

预期：403，数据库无新增记录。
注入基线实际：服务信任客户端 owner_id 并返回 201。

## 影响、根因与修复

攻击者可骚扰老人、制造虚假用药提醒。根因是只做角色校验，未做对象关系校验。修复在每个提醒 CRUD 操作中调用 `_owner_or_403()` 和 active 绑定检查。

回归证据：`test_unlinked_family_cannot_create_reminder`、`test_linked_family_can_create_reminder`。
