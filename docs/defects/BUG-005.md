# BUG-005 注册/资料响应暴露完整手机号

- 类型：PII 暴露 / 缺陷注入与回归演练
- 严重度：S1；优先级：P0；状态：Verified
- 影响版本：fault-injection baseline；修复版本：1.0.0

## 复现步骤

1. 注册任一账号或请求 `/auth/me`。
2. 检查 JSON 是否含 `phone` 原值或密码相关字段。

预期：只含 `phone_masked`，格式为前三位 + `****` + 后四位；无密码字段。
注入基线实际：ORM 用户对象直接序列化，完整手机号可见。

## 影响、根因与修复

根因是数据实体与公开响应模型未分离。修复引入白名单式 `UserRead` 和统一 `to_user_read()`；不允许 ORM 自动暴露新增列。

回归证据：`test_register_success_returns_masked_profile`、`test_me_never_exposes_full_phone`、Postman 注册断言。
