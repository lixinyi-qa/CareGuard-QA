# BUG-011 异步提交成功后表单不重置且页面不刷新

- 类型：前端异步状态 / 真实预发布缺陷
- 严重度：S2；优先级：P0；状态：Verified
- 发现版本：1.0.0-rc1；修复版本：1.0.0
- 发现方式：真实 Chrome + Playwright 第三轮回归

## 复现步骤

1. 注册并进入老人端。
2. 在首页填写心情文字并点击“记录心情”。
3. 观察网络请求、输入框、最近心情和历史记录。

预期：POST 返回 201 后清空输入、出现成功反馈，并刷新卡片和历史。
实际：POST 已返回 201，但输入未清空、卡片未更新；浏览器控制台出现对 `null.reset()` 的调用错误。提醒、绑定、联系人表单存在同类风险。

## 根因与修复

异步事件处理器在 `await request()` 之后使用 `event.currentTarget`。DOM 事件派发结束后 `currentTarget` 会恢复为 `null`，因此调用 `reset()` 抛错并中断后续 UI 更新。

修复为在第一个 `await` 之前保存 `const form = event.currentTarget`，心情、提醒、绑定和联系人四条提交路径统一使用稳定引用。退出流程同时显式切回登录 Tab，解决同轮测试发现的状态残留。

回归证据：`tests/ui/test_accessible_flows.py::test_elderly_can_submit_mood_and_view_history`，最终 Chromium JUnit 报告 `outputs/ui-test-report.xml`。
